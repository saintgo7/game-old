# 🎮 게임 004 - BREAKOUT (벽돌깨기)

## 게임 설명
공으로 화면 위의 벽돌들을 깨뜨리는 게임입니다.

## 조작 방법
- **← (LEFT)**: 패들 좌로 이동
- **→ (RIGHT)**: 패들 우로 이동

## 규칙
- 패들로 공을 반사시켜 벽돌을 깨뜨립니다
- 모든 벽돌을 깨면 승리
- 공이 바닥에 떨어지면 게임 오버
- 깨진 벽돌당 +10점

## 설치 및 실행
```bash
cd games/001-050/game_004_breakout
pip install -r requirements.txt
python main.py
```
