# 🎮 게임 003 - TETRIS (테트리스)

## 게임 설명

떨어지는 테트로미노 블록을 회전하고 이동시켜 가로줄을 완성시키는 고전 퍼즐 게임입니다.

## 게임 규칙

1. 테트로미노 블록이 위에서 아래로 떨어집니다
2. 블록을 회전하고 이동시켜 가로줄을 완성합니다
3. 완성된 줄은 제거되고 점수를 얻습니다
4. 블록이 화면 위까지 쌓이면 게임이 끝납니다

## 조작 방법

| 키 | 동작 |
|---|---|
| **← (LEFT)** | 블록 좌로 이동 |
| **→ (RIGHT)** | 블록 우로 이동 |
| **↓ (DOWN)** | 블록 빠르게 하강 |
| **↑ (UP)** | 블록 회전 |
| **ESC** | 게임 종료 |

## 점수 체계

| 상황 | 점수 |
|------|------|
| 1줄 완성 | +100점 |
| 500점마다 | 레벨 +1, 속도 증가 |

## 팁과 트릭

1. **미리 계획하세요**: 블록을 배치할 위치를 미리 생각하세요
2. **쌓기**: 블록을 균등하게 쌓으세요
3. **빈 공간**: 세로 줄을 남겨 I 모양 블록을 위해 준비하세요
4. **속도**: 속도가 빨라질수록 더 빠르게 결정해야 합니다

## 설치 및 실행

```bash
cd games/001-050/game_003_tetris
pip install -r requirements.txt
python main.py
```
