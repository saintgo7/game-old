# 🎮 게임 001 - PONG (탁구)

## 게임 설명

PONG은 가장 오래된 고전 아케이드 게임 중 하나입니다. 두 명의 플레이어가 각각 화면 양쪽 끝의 패들을 조종하여 공을 반사시키는 게임입니다.

## 게임 규칙

1. 공이 화면을 왕복하며 움직입니다
2. 각 플레이어는 패들을 위아래로 움직여 공을 반사시킵니다
3. 상대방의 패들로 공을 반사하지 못하면 상대방이 점수를 얻습니다
4. 먼저 11점을 획득한 플레이어가 게임을 이깁니다

## 조작 방법

### 왼쪽 패들 (1P)
- **W 키**: 패들 위로 이동
- **S 키**: 패들 아래로 이동

### 오른쪽 패들 (2P)
- **↑ (UP) 키**: 패들 위로 이동
- **↓ (DOWN) 키**: 패들 아래로 이동

### 기타
- **ESC 또는 창 닫기**: 게임 종료
- **SPACE**: 게임 오버 후 새 게임 시작

## 점수 체계

| 상황 | 점수 |
|------|------|
| 공을 반사하지 못함 | +1점 |
| 먼저 11점 도달 | 승리 |

## 팁과 트릭

1. **각도 조절**: 패들의 위쪽 또는 아래쪽으로 공을 칠하면 공의 각도가 변합니다
2. **타이밍**: 공이 패들의 중앙에 맞으면 더 정확한 반사가 가능합니다
3. **예측**: 공의 궤적을 예측하고 미리 패들을 이동시키세요
4. **속도**: 공의 속도는 라운드가 진행될수록 빨라집니다

## 코드 구조

### 주요 클래스

#### Paddle 클래스
```python
- __init__(x, y): 패들 초기화
- move_up(): 패들 위로 이동
- move_down(): 패들 아래로 이동
- draw(screen): 패들 그리기
```

#### Ball 클래스
```python
- __init__(): 공 초기화
- update(): 공 위치 업데이트
- reset(): 공 초기 위치로 복구
- draw(screen): 공 그리기
```

#### PongGame 클래스
```python
- __init__(): 게임 초기화
- handle_events(): 이벤트 처리
- handle_input(): 입력 처리
- update(): 게임 로직 업데이트
- draw(): 화면 렌더링
- reset_game(): 게임 초기화
- run(): 메인 게임 루프
```
