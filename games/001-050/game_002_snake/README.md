# 🎮 게임 002 - SNAKE (뱀)

## 게임 설명

뱀을 조종하여 화면에 나타나는 음식을 먹고, 뱀이 자신의 몸에 부딪히거나 벽에 부딪히지 않도록 조절하는 게임입니다.

## 게임 규칙

1. 뱀은 항상 움직이고 있습니다
2. 화면에 나타나는 빨간 음식을 먹으면 점수를 얻습니다
3. 음식을 먹을 때마다 뱀의 길이가 1칸씩 증가합니다
4. 뱀이 벽에 부딪히거나 자신의 몸에 부딪히면 게임이 끝납니다
5. 점수가 높을수록 뱀의 속도가 빨라집니다

## 조작 방법

| 키 | 동작 |
|---|---|
| **↑ (UP)** | 뱀을 위로 이동 |
| **↓ (DOWN)** | 뱀을 아래로 이동 |
| **← (LEFT)** | 뱀을 좌로 이동 |
| **→ (RIGHT)** | 뱀을 우로 이동 |
| **SPACE** | 게임 오버 후 새 게임 시작 |
| **ESC** | 게임 종료 |

## 점수 체계

| 상황 | 점수 |
|------|------|
| 음식 먹기 | +10점 |
| 50점마다 | 속도 +1 증가 |

## 팁과 트릭

1. **계획을 세우세요**: 뱀이 자신의 몸에 부딪히지 않도록 경로를 미리 계획하세요
2. **가장자리를 피하세요**: 벽 근처에서는 주의깊게 이동하세요
3. **속도 적응**: 속도가 빨라질수록 더 신중하게 움직이세요
4. **시각적 계산**: 뱀의 길이를 고려하여 이동 경로를 결정하세요

## 코드 구조

### 주요 클래스

#### Snake 클래스
```python
- __init__(): 뱀 초기화
- move(): 뱀 이동
- grow(): 뱀 길이 증가 (자동)
- check_collision(): 자기 몸과 충돌 확인
- check_bounds(): 경계 충돌 확인
- draw(screen): 뱀 그리기
```

#### Food 클래스
```python
- __init__(): 음식 초기화
- respawn(snake_body): 새로운 위치에 음식 생성
- draw(screen): 음식 그리기
```

#### SnakeGame 클래스
```python
- __init__(): 게임 초기화
- handle_events(): 이벤트 처리
- update(): 게임 업데이트 (이동, 충돌 감지)
- draw(): 화면 렌더링
- reset_game(): 게임 초기화
- run(): 메인 게임 루프
```
