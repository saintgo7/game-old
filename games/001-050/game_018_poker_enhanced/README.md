# 🎮 게임 018 - Poker (포커) (Enhanced)

## 개선 사항

✅ **하이스코어 시스템**
- 상위 10개 점수 저장
- 플레이어 이름 기록

✅ **멀티플레이 지원**
- 로컬 멀티플레이 (M 키)
- 네트워크 멀티플레이 준비

✅ **사운드 시스템**
- 효과음 및 배경음악
- 볼륨 조절 (설정)

✅ **테마 시스템**
- 7가지 테마 지원
- 설정에서 선택 가능

✅ **게임 설정**
- 난이도 선택
- 플레이어 이름 설정
- 사운드/음악 볼륨 조절

## 키 설정

- **P**: 게임 일시정지
- **H**: 하이스코어 표시
- **M**: 멀티플레이 모드 전환
- **ESC**: 게임 종료
- **SPACE**: 게임 오버 후 재시작

## 테마 목록

- Classic (검은 배경, 흰색 텍스트)
- Dark (어두운 배경)
- Light (밝은 배경)
- Neon (네온 스타일)
- Retro (복고풍)
- Forest (숲 테마)
- Ocean (바다 테마)

## 설정 파일

~/.arcade_games/config/poker.json
